## 2024-05-15 - [Enhanced Contact Usability & Global Accessibility]
**Learning:** Icon-only buttons without labels are a common accessibility gap in modern UI frameworks. Providing immediate visual feedback for interactive actions like "Copy to Clipboard" (e.g., swapping icons for 2 seconds) significantly improves user confidence and perceived responsiveness.
**Action:** Always audit icon-only buttons for `aria-label` and implement state-driven feedback for clipboard operations.
